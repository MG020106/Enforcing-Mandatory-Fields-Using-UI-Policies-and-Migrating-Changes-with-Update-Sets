# 📌 Enforcing Mandatory Fields Using UI Policies and Migrating Changes with Update Sets

## 📖 Overview
This project demonstrates how to enforce mandatory fields dynamically using UI Policies in ServiceNow and migrate configurations using Update Sets.

---

## ❗ Problem Statement
Users often submit incomplete forms which leads to poor data quality and delays.

---

## 🎯 Objective
- Create a custom table
- Apply UI Policies
- Test mandatory fields
- Migrate using Update Sets

---

## 🛠️ Technologies Used
- ServiceNow
- UI Policies
- Update Sets

---

## 🧩 Modules
### 1. Table Creation
Student Request table with fields:
- Name
- Request Type
- Reason
- Manager Approval

### 2. UI Policy
Condition:
- Request Type = Leave

Action:
- Make Reason mandatory
- Make Manager Approval mandatory

### 3. Testing
- Leave selected → Fields mandatory
- Other → Not mandatory

### 4. Update Sets
- Create update set
- Capture changes
- Export & import

---

## ✅ Result
- Dynamic validation achieved
- Data quality improved
- Easy migration
