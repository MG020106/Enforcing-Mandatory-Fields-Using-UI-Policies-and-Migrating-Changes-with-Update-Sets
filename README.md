# Enforcing-Mandatory-Fields-Using-UI-Policies-and-Migrating-Changes-with-Update-Sets
# ServiceNow UI Policy & Update Set Project

## Overview
This project demonstrates enforcing mandatory fields using UI Policies and migrating configurations using Update Sets.

## Features
- Dynamic field validation
- No scripting required
- Easy migration using Update Sets

## Tools Used
- ServiceNow Platform

## Steps
1. Create table
2. Apply UI policy
3. Test conditions
4. Capture in Update Set

## Outcome
Improved data quality and efficient migration process.
